# Password and Authentication Policy
SYNTHETIC DEMONSTRATION POLICY
NOT AN ACTUAL ORGANIZATION POLICY

## 1. Password requirements
Human account passwords must contain at least sixteen characters. Passphrases are allowed. Password reuse across cooperative accounts is prohibited; users store secrets in the approved password manager. A compromised password must be changed immediately.

## 2. Multifactor authentication
Multifactor authentication is required for all workforce accounts accessing cooperative applications. Hardware security keys are preferred for administrators. SMS is allowed only as a documented thirty-day recovery exception approved by the Security Steward.

## 3. Recovery and service credentials
Help desk recovery requires identity verification through a separate registered channel. Recovery codes are Restricted data. Service account credentials are rotated every ninety days and stored in the approved secrets vault, never in source code.

## 4. Failed sign-ins
After ten failed authentication attempts in fifteen minutes, an account is paused for fifteen minutes and the Security Steward is notified. The pause must not silently disable incident reporting.
